Chaudhary Charan Singh University (CCSU), Meerut offers a rigorous 3-Year (6 Semesters) Bachelor of Computer Applications (BCA) degree designed to equip students with software development, algorithmic thinking, database administration, mathematical foundations, and IT management capabilities.

Below is the complete academic syllabus breakdown, course code mapping, marks distribution (Theory: 75M External + 25M Internal; Practical: 50M), and semester-wise examination blueprints for all 6 semesters.

📊 CCSU BCA Evaluation System & Marking Scheme

Degree Structure: 6 Semesters · 3600 Total Marks

Each semester in CCSU BCA carries 600 Marks (5 Theory papers × 100 Marks = 500 Marks, plus 2 Practical Lab courses × 50 Marks = 100 Marks). Across all 3 years, students appear for 30 theory papers and 12 practical/viva examinations totaling 3600 Marks.

BCA 3rd to 6th Semester Curriculum Summary

Senior semesters build specialized software engineering capabilities, database management systems (DBMS), Java object-oriented programming, operating system internals, web development, and major capstone projects.

Semester 3 (Year 2)

Data Structures using C, Object Oriented Programming with C++, Operating Systems, Elements of Statistics, Software Engineering, and Practical Labs.

Semester 4 (Year 2)

Computer Graphics, Database Management Systems (DBMS), Java Programming, Numerical Methods & Optimization, and Practical Labs.

Semester 5 (Year 3)

Computer Networks & Security, Web Technologies (HTML, CSS, JavaScript, PHP), Advanced Java / Dot Net Framework, and Minor Live Project.

Semester 6 (Year 3)

E-Commerce, Information Security, Cloud Computing / Data Science, Major Industry Project, and Comprehensive Degree Viva Voce.

CCSU University Examination & Passing Rules:

  • Theory Minimum: 40% marks in external theory exam (minimum 30 out of 75 Marks) and 40% aggregate in each theory subject.
  • Practical Minimum: 40% marks in practical viva and computer lab execution (minimum 20 out of 50 Marks).
  • Question Paper Structure: Section A (5 questions × 3 marks = 15 Marks compulsory), Section B (attempt 2 of 3 questions × 7.5 marks = 15 Marks), and Section C (attempt 3 of 5 questions × 15 marks = 45 Marks).
