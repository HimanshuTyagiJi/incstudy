C & C++ Programming Language Core Blueprint

Essential language mechanics, storage class lifetimes, memory layout, operator precedence, and object-oriented rules frequently tested in Section A (3M) and Section B (7.5M).

1. Storage Classes in C (Scope & Lifetime)

Storage Class Storage Default Scope Lifetime

register CPU Register Garbage Local block End of block
static Data Segment Zero (0) Local / File Entire program
extern Data Segment Zero (0) Global / Multi-file Entire program

Exam Keynote: Address-of operator (&) cannot be applied to register variables because they reside in CPU registers, not main memory.

2. C++ Dynamic Polymorphism & VTABLE Mechanism

  • Early vs Late Binding: Normal functions bind at compile time (early). Declaring a base class function with virtual forces late (dynamic) binding at runtime via base pointer.
  • VTABLE & VPTR: When a class contains a virtual function, the compiler inserts a hidden Virtual Table Pointer (_vptr) inside each object pointing to a static array of function pointers (VTABLE).
  • Pure Virtual Functions: virtual void draw() = 0; makes a class Abstract. Objects of abstract classes cannot be instantiated; derived classes must override all pure virtual functions.
  • Diamond Problem Resolution: When Class D inherits from B and C, which both inherit from A, declare inheritance as virtual public A in B and C to maintain only one shared copy of A in D.

Computer Architecture & 8085 Microprocessor Summary

Core CPU micro-operations, register transfers, addressing modes, and hardware control logic tested in BCA-303.

1. Microprocessor 8085 Internal Register Map

  • Accumulator (A - 8 bits): Primary register for all arithmetic and logical operations, stores the primary operand and computation result.
  • General Purpose Registers (B, C, D, E, H, L): 6 registers of 8 bits each. Can be used individually or combined into 16-bit register pairs: B-C, D-E, and H-L (acts as memory pointer M).
  • Program Counter (PC - 16 bits): Holds the memory address of the next instruction to be fetched and executed. Auto-increments after each fetch.
  • Stack Pointer (SP - 16 bits): Holds the memory address of the current top of the stack located in RAM (decrements on PUSH, increments on POP).
  • 8-bit Flag Register: Contains 5 hardware status flip-flops:
    [ S | Z | X | AC | X | P | X | CY ]
    • S (Sign): 1 if MSB ($D_7$) is 1 (negative result).
    • Z (Zero): 1 if ALU result is strictly zero.
    • AC (Auxiliary Carry): 1 if carry generated from $D_3$ to $D_4$ (used in BCD).
    • P (Parity): 1 if result has an even number of 1s.
    • CY (Carry): 1 if addition/subtraction overflows 8 bits.

2. Instruction Cycle RTL & Addressing Modes

  • The 4 Stages of Instruction Cycle:
    • Fetch ($T_0, T_1$): $AR \leftarrow PC$, then $IR \leftarrow M[AR], PC \leftarrow PC + 1$.
    • Decode ($T_2$): Decode opcode in $IR(12-14)$, $AR \leftarrow IR(0-11)$, check mode bit $I = IR(15)$.
    • Effective Address ($T_3$): If indirect ($I=1$), $AR \leftarrow M[AR]$.
    • Execute ($T_4 \dots$): Perform operation according to decoded command.
  • Addressing Modes Quick Reference:
    • Immediate: Operand is inside instruction (e.g. MVI A, 32H).
    • Direct: Instruction contains memory address (e.g. LDA 2050H).
    • Register: Operand resides in register (e.g. MOV A, B).
    • Register Indirect: Address in register pair (e.g. MOV A, M via HL).
    • Implied: Operand implied by opcode (e.g. CMA, RAL).

Mathematics & Statistics University Formula Sheet

Core formulas for Calculus, Successive Differentiation, Matrices, Central Tendency, Correlation, and Regression tested in BCA-101 and BCA-305.

1. Mathematics - I (BCA-101) Core Formulas

  • Leibnitz's Theorem ($n^{\text{th}}$ Derivative of Product $uv$):
    (uv)_n = u_n v + nC1 u_(n-1) v_1 + nC2 u_(n-2) v_2 + ... + u v_n
  • Euler's Theorem for Homogeneous Functions of Degree $n$:
    x (∂u/∂x) + y (∂u/∂y) = n · u
  • Cayley-Hamilton Theorem: Every square matrix $A$ satisfies its own characteristic equation:
    |A - λI| = 0 => A^n + c_(n-1) A^(n-1) + ... + c_0 I = 0
  • Taylor's Expansion in Powers of $(x - a)$:
    f(x) = f(a) + (x-a) f'(a) + [(x-a)^2 / 2!] f''(a) + ...
  • Standard Reduction Formula:
    ∫ sin^n x dx = - (sin^(n-1) x cos x)/n + [(n-1)/n] ∫ sin^(n-2) x dx

2. Elements of Statistics (BCA-305) Core Formulas

  • Empirical Relationship:
    Mode = 3 · Median - 2 · Mean
  • Continuous Median & Mode:
    Median = L + [ (N/2 - c.f.) / f ] × h
    Mode = L + [ (f1 - f0) / (2f1 - f0 - f2) ] × h
  • Standard Deviation & Coefficient of Variation:
    σ = √[ (Σfd² / N) - (Σfd / N)² ] × h
    C.V. = (σ / X̄) × 100
  • Karl Pearson's Correlation Coefficient ($r$):
    r = Σxy / √[ (Σx²) · (Σy²) ] where x = X - X̄, y = Y - Ȳ
  • Two Linear Regression Equations:
    Y - Ȳ = b_yx (X - X̄) where b_yx = r (σ_y / σ_x)
    X - X̄ = b_xy (Y - Ȳ) where b_xy = r (σ_x / σ_y)
    Property: r = ± √(b_yx · b_xy)
  • Fisher's Ideal Index Number:
    P_01^F = √[ (Σp1 q0 / Σp0 q0) × (Σp1 q1 / Σp0 q1) ] × 100
