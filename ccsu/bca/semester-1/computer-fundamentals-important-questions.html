Q6. What is the role of I/O Devices in a computer? Why are they necessary?

🔥 Repeated: 2012, 2013, 2020 3 Marks
✍️ Model Answer:

A computer's central processor only understands binary signals ($0$ and $1$). Input/Output (I/O) devices serve as the essential bridge between the human user and the digital computer:

  • Input Devices (Keyboard, Mouse, Scanner): Accept human-understandable data (keystrokes, audio, clicks) and convert them into binary machine code for the CPU.
  • Output Devices (Monitor, Printer, Speaker): Translate processed binary output back into human-perceptible formats (visual images, printed text, audio). Without I/O devices, a computer would be an isolated, unusable black box.

Q7. Define Seek Time, Latency Time, and Access Time of a Hard Disk.

🔥 Repeated: 2013 3 Marks
✍️ Model Answer:
  • Seek Time: The time required for the magnetic Read/Write head assembly to move across platters to position itself directly over the target cylinder/track ($4\text{ to }10\text{ ms}$).
  • Latency Time (Rotational Delay): The time taken for the rotating magnetic disk to spin the requested sector under the read/write head. Average Latency $= \frac{1}{2 \times \text{RPM}}$.
  • Access Time: The total time elapsed between issuing a read/write command and when data transmission begins: $$\mathbf{\text{Access Time} = \text{Seek Time} + \text{Latency Time} + \text{Transfer Time}}$$

Q8. Differentiate between Cache Memory and Virtual Memory.

🔥 Repeated: 2014, 2016 3 Marks
✍️ Model Answer:
  • Cache Memory: Physical high-speed semiconductor Static RAM (SRAM) located on or adjacent to the CPU chip. It stores frequently used instructions to eliminate CPU idle wait states caused by slower Main RAM.
  • Virtual Memory: A software/OS memory management technique that reserves a portion of the secondary hard disk (Pagefile/Swap Space) to simulate extra RAM, allowing programs larger than physical memory to execute via Paging.

Q9. What is an IC (Integrated Circuit)? How did it help in reducing the size of computers?

🔥 Repeated: 2014 3 Marks
✍️ Model Answer:

An Integrated Circuit (IC / Microchip) is a miniature electronic circuit fabricated onto a tiny semiconductor wafer (silicon) that integrates thousands to billions of transistors, diodes, resistors, and capacitors into a single package.

How ICs Revolutionized Computer Size: Before ICs, 2nd-generation computers relied on bulky, discrete transistors wired manually. ICs allowed millions of components to fit within a fingernail-sized silicon chip, drastically reducing physical computer size from entire rooms (3rd Gen: SSI/MSI) down to desktop and handheld microprocessors (4th Gen: VLSI/ULSI), while multiplying processing speeds and lowering heat generation.

Q10. Explain the effect of the DOS command: dir | sort | more.

🔥 Repeated: 2013 3 Marks
✍️ Model Answer:

This command combines three DOS utilities using pipe operators (|) that redirect the standard output of one command as the input of the next:

  1. dir: Lists all files and subdirectories in the current directory.
  2. | sort: Pipes that directory listing into the sort filter, arranging the file names alphabetically in ascending order.
  3. | more: Pipes the sorted output through the paginator, displaying one full screen of files at a time and pausing with -- More -- until the user presses any key.

Q23. Memory Classification: Differentiate between RAM and ROM. Explain PROM, EPROM, and EEPROM. Differentiate Main Memory vs Auxiliary Memory.

🔥 Appeared in All 10 Years (2011–2020) 15 Marks
✍️ Model Answer:
ParameterRAM (Random Access Memory)ROM (Read Only Memory)
VolatilityVolatile: Data lost instantly when power is cut.Non-Volatile: Retains stored data permanently without power.
OperationRead and Write operations.Read-only during normal computing.
Stored ContentActive programs, OS runtime files, user data.BIOS firmware and bootstrap loader.
SpeedHigh speed (nanoseconds).Slower than RAM.

The ROM Family:

  1. PROM (Programmable ROM): Manufactured blank; can be programmed once using electrical high voltage (blowing internal microscopic fuses). Cannot be erased afterwards.
  2. EPROM (Erasable Programmable ROM): Contains a transparent quartz crystal window. Exposing the chip to intense Ultraviolet (UV) radiation for 20–30 minutes erases all stored data, allowing reprogramming.
  3. EEPROM (Electrically Erasable Programmable ROM): Can be erased and rewritten electrically byte-by-byte without removing the chip. Modern Flash Memory (SSDs, USB Pen Drives, BIOS chips) is based on EEPROM technology.

Main Memory vs Auxiliary (Secondary) Memory:

  • Main Memory (RAM): Directly accessed by CPU via address/data buses; fast, volatile, and limited in capacity (8GB–32GB).
  • Auxiliary Memory (HDD/SSD/Optical): Not directly accessed by CPU; non-volatile, massive capacity (512GB–4TB), highly economical per gigabyte, but thousands of times slower than RAM.

Q24. What is an Operating System? Explain its major functions. Differentiate between Multiprogramming, Multitasking, and Multiprocessing.

🔥 Repeated in 8 Out of 10 Papers 15 Marks
✍️ Model Answer:

An Operating System (OS) is system software that acts as an intermediary interface between computer hardware and the user/applications, managing hardware resources efficiently.

Five Major Functions of an Operating System:

  1. Processor Management (CPU Scheduling): Allocates CPU time to active processes using scheduling algorithms (Round Robin, FCFS, Priority).
  2. Memory Management: Keeps track of every memory byte, dynamically allocates RAM to running programs, and deallocates upon program termination.
  3. File System Management: Manages directories, files, read/write permissions, and disk sector allocation (FAT32, NTFS, EXT4).
  4. Device Management (I/O): Communicates with peripheral hardware using device drivers, managing input/output buffers and Spooling (Print spooler).
  5. Security & Error Handling: Protects user data through authentication, passwords, firewall, and handles hardware/software exceptions.

Multiprogramming vs Multitasking vs Multiprocessing:

TypeCore MechanismCPUs / Cores
MultiprogrammingMultiple programs reside in RAM simultaneously. When one waits for I/O, CPU switches to another to prevent CPU idle time.Single CPU.
Multitasking (Time-Sharing)Logical extension of multiprogramming. CPU time is divided into microscopic slices (quanta), rapidly switching so user feels all apps run at once.Single CPU.
MultiprocessingExecuting multiple processes concurrently using two or more physical CPUs or cores simultaneously.Multiple CPUs / Multicore.

Q25. MS-DOS Architecture: Significance of `CONFIG.SYS`, `AUTOEXEC.BAT`, and `COMMAND.COM`. Describe Directives (FILES, BUFFERS, DEVICE). Explain Batch Files.

🔥 Repeated in 9 Out of 10 Papers 15 Marks
✍️ Model Answer:

Three Fundamental Files in MS-DOS:

  • `COMMAND.COM`: The DOS Command Processor and shell. It displays the command prompt (C:\>), parses user input, and contains all internal commands in resident memory.
  • `CONFIG.SYS`: Configuration text file evaluated by the DOS kernel at initial boot. Key directives include:
    • FILES=40: Specifies the maximum number of files DOS can open simultaneously.
    • BUFFERS=20: Allocates memory cache buffers for disk transfers.
    • DEVICE=C:\DOS\HIMEM.SYS: Loads device drivers for hardware into memory.
    • COUNTRY=001: Sets international date, time, and currency formats.
    • SHELL=C:\DOS\COMMAND.COM /P: Specifies alternate command interpreter location.
  • `AUTOEXEC.BAT`: Automatic Execution Batch file executed immediately after `CONFIG.SYS`. Sets system paths (PATH C:\DOS;C:\TC\BIN), prompt styles, and starts default programs.

Batch Files in DOS:

A Batch File (.bat) is an uncompiled text script containing a series of sequential DOS commands executed line-by-line automatically.

:: Create a batch file to backup student files
COPY CON backup.bat
@ECHO OFF
ECHO Backing up documents for %1 ...
IF NOT EXIST C:\BACKUP MD C:\BACKUP
COPY C:\DATA\%1\*.* C:\BACKUP\
ECHO Backup of %1 Complete!
^Z (Press Ctrl+Z and Enter to save)

Q31. What is Assembly Language? Explain its advantages and disadvantages over Machine Level Language. Explain features of DOS.

🔥 Repeated: 2020 15 Marks
✍️ Model Answer:

Assembly Language: A low-level programming language that replaces obscure binary machine code with human-readable symbolic abbreviations called Mnemonics (e.g., MOV AX, BX; ADD AX, 05; JMP loop).

Advantages over Machine Level Language:

  • Easier to Understand and Code: Using mnemonics instead of long strings of 0s and 1s makes programming far less error-prone.
  • Easier Debugging: Locating errors in assembly syntax is straightforward compared to checking binary digits.
  • Symbolic Addressing: Variables and memory locations are given symbolic names (e.g., SUM, COUNT) rather than absolute hexadecimal hardware addresses.

Disadvantages:

  • Machine Dependent: Assembly programs written for Intel x86 processors cannot execute on ARM or RISC processors.
  • Requires Translation: Requires an Assembler program to convert mnemonics into executable binary machine code before execution.
