Q1. What do you understand by Identifiers in C? State their naming rules.

🔥 Repeated: 2015, 2017, 2019 3 Marks
✍️ Model Answer:

An Identifier is a user-defined name given to program elements such as variables, functions, arrays, and structures to uniquely identify them during program execution.

Rules for Naming Identifiers in C:

  • Can contain letters (a–z, A–Z), digits (0–9), and underscore (_).
  • Must begin with an alphabet letter or an underscore; it cannot begin with a digit.
  • Cannot be a reserved C keyword (e.g., int, while, return).
  • C is case-sensitive; count, Count, and COUNT are three distinct identifiers.
  • No special characters (like @, $, #, space) are permitted.
// Valid: student_age, _totalMarks, marks1
// Invalid: 1marks (starts with digit), total marks (space), float (keyword)

Q3. What do you understand by C Tokens? List all categories.

🔥 Repeated: 2016 3 Marks
✍️ Model Answer:

A C Token is the smallest individual building block or basic grammatical unit of a C program that the compiler recognizes and parses.

There are 6 categories of C Tokens:

  1. Keywords: 32 reserved words having predefined meaning (e.g., int, if, return).
  2. Identifiers: User-defined names for variables and functions (e.g., total, calculateSum).
  3. Constants: Fixed literal values (e.g., 100, 3.14, 'A').
  4. Strings: Sequence of characters enclosed in double quotes (e.g., "CCSU BCA").
  5. Special Symbols: Punctuation characters with syntactical meaning (e.g., [], {}, ;, ,).
  6. Operators: Symbols that perform mathematical or logical operations (e.g., +, *, &&, ==).

Q4. What do you understand by Time Complexity of an algorithm?

🔥 Repeated: 2015, 2016, 2017, 2019 3 Marks
✍️ Model Answer:

Time Complexity is a measure of the computational time an algorithm takes to execute as a function of the input size $n$.

  • It does not measure physical execution time in seconds (as clock time varies across CPU hardware), but counts the total number of elementary operations / steps performed.
  • It is mathematically represented using asymptotic notations: Big-Oh ($O$), Big-Omega ($\Omega$), and Big-Theta ($\Theta$).
  • Example: Searching an element in an unsorted array of size $n$ takes $O(n)$ time in the worst case (Linear Search).

Four Common Preprocessor Directives:

C is known as a Procedural (or Procedure-Oriented) Language because:

  • Programs are organized as a sequence of procedural steps, subroutines, or functions that perform operations on data.

🔥 Repeated: 2020 3 Marks

void swap(int *x, int *y) {
    int temp = *x; // Dereference pointer to get value
    *x = *y;
    *y = temp;
}

int main() {
    int a = 10, b = 20;
    printf("Before Swap: a = %d, b = %d\n", a, b);

}

Q18. Explain the Tower of Hanoi problem. Write down its recursive algorithm for $N$ disks.

🔥 Repeated: 2018 7.5 Marks
✍️ Model Answer:

Tower of Hanoi is a classic recursive puzzle consisting of three vertical pegs or towers: Source (A), Auxiliary / Helper (B), and Destination (C), with $N$ disks of different diameters.

Rules of the Puzzle:

  1. Only one disk can be moved at a time.
  2. A disk can only be taken from the top of one peg and placed on top of another.
  3. No larger disk can ever be placed on top of a smaller disk.

Recursive Strategy for $N$ Disks:

  • Step 1: Recursively move top $N-1$ disks from Source (A) to Auxiliary (B) using Destination (C).
  • Step 2: Move the remaining $N$-th (largest) disk directly from Source (A) to Destination (C).
  • Step 3: Recursively move $N-1$ disks from Auxiliary (B) to Destination (C) using Source (A).
#include <stdio.h>

void towerOfHanoi(int n, char from_peg, char to_peg, char aux_peg) {
    if (n == 1) { // Base Case
        printf("Move disk 1 from %c to %c\n", from_peg, to_peg);
        return;
    }
    towerOfHanoi(n - 1, from_peg, aux_peg, to_peg);
    printf("Move disk %d from %c to %c\n", n, from_peg, to_peg);
    towerOfHanoi(n - 1, aux_peg, to_peg, from_peg);
}

int main() {
    int n = 3; // 3 disks
    printf("Steps for 3 disks:\n");
    towerOfHanoi(n, 'A', 'C', 'B'); // Total steps = 2^3 - 1 = 7
    return 0;
}
Mathematical Complexity: For $N$ disks, total moves required $= 2^N - 1$. Time Complexity is exponential: $O(2^N)$. Space Complexity is $O(N)$ for recursion call stack.

Q26. Define Asymptotic Notations: Big-Oh ($O$), Big-Omega ($\Omega$), and Big-Theta ($\Theta$). Explain best, average, and worst-case complexity analysis.

🔥 Repeated: 2017, 2018, 2019 15 Marks
✍️ Model Answer:

Asymptotic Notations are mathematical notations used to describe the limiting behavior and growth rate of an algorithm's execution time as the input size $n$ tends to infinity ($n \to \infty$).

1. Big-Oh Notation ($O$) — Upper Bound (Worst-Case):

Big-Oh defines the maximum time an algorithm can take for any input of size $n$. It represents the worst-case ceiling.

Mathematical Definition: $f(n) = O(g(n))$ if there exist positive constants $c > 0$ and $n_0 \ge 1$ such that: $$0 \le f(n) \le c \cdot g(n) \quad \forall \; n \ge n_0$$

2. Big-Omega Notation ($\Omega$) — Lower Bound (Best-Case):

Big-Omega defines the minimum execution time required by an algorithm. It represents the best-case floor.

Mathematical Definition: $f(n) = \Omega(g(n))$ if there exist positive constants $c > 0$ and $n_0 \ge 1$ such that: $$0 \le c \cdot g(n) \le f(n) \quad \forall \; n \ge n_0$$

3. Big-Theta Notation ($\Theta$) — Tight Bound (Average-Case):

Big-Theta defines both the lower and upper bounds simultaneously. It represents the exact asymptotic rate of growth.

Mathematical Definition: $f(n) = \Theta(g(n))$ if there exist positive constants $c_1, c_2 > 0$ and $n_0 \ge 1$ such that: $$0 \le c_1 \cdot g(n) \le f(n) \le c_2 \cdot g(n) \quad \forall \; n \ge n_0$$

📈 GRAPHICAL PROOF : Asymptotic Curves & Threshold $n_0$ Exam Answer Sheet Diagram

Algorithm: Finding Maximum Element of an Array with Complexity Analysis:

int findMax(int arr[], int n) {
    int max = arr[0];          // Step 1: 1 operation
    for (int i = 1; i < n; i++) { // Loop runs (n - 1) times
        if (arr[i] > max)      // Comparison: (n - 1) times
            max = arr[i];
    }
    return max;                // 1 operation
}
  • Best Case: Elements in descending order (e.g., $[10, 8, 5, 2]$). Number of comparisons $= n - 1$. Complexity is $\Omega(n)$.
  • Worst Case: Elements in ascending order (e.g., $[2, 5, 8, 10]$). Comparison and assignment occur every iteration. Complexity is $O(n)$.
  • Average Case: Elements in random order. Still requires $(n-1)$ comparisons. Complexity is $\Theta(n)$.

Q27. Explain all types of Operators in C with complete syntax, precedence, and associativity.

🔥 Repeated: 2017, 2018, 2023 15 Marks
✍️ Model Answer:

An Operator is a special character or symbol that instructs the compiler to perform specific mathematical, relational, or logical manipulations on operands.

Classification of Operators in C:

  1. Arithmetic Operators: + (Addition), - (Subtraction), * (Multiplication), / (Quotient division), % (Modulus remainder — operates only on integers).
  2. Relational Operators: Used for comparison; evaluate to 1 (True) or 0 (False): ==, !=, >, <, >=, <=.
  3. Logical Operators: Combine conditions:
    • && (Logical AND): True only if both operands are non-zero.
    • || (Logical OR): True if at least one operand is non-zero.
    • ! (Logical NOT): Inverts condition.
  4. Bitwise Operators: Work at the binary bit level: & (AND), | (OR), ^ (XOR), ~ (1's Complement), << (Left shift), >> (Right shift).
  5. Increment & Decrement Operators:
    • Prefix (++a): Increments first, then evaluates in expression.

Q29. Explain Problem Solving Techniques: Divide and Conquer, Brainstorming, and Trial & Error.

🔥 Repeated: 2015, 2016, 2019 15 Marks
✍️ Model Answer:

Problem-solving techniques are structured mental and algorithmic frameworks used by computer scientists to break down complex real-world requirements into computable software.

1. Divide and Conquer:

This technique breaks a large, complex problem down into multiple independent, smaller sub-problems of the same type, solves them recursively, and combines their solutions:

  • Divide: Partition problem $P$ into smaller subproblems $P_1, P_2, \dots, P_k$.
  • Conquer: Solve subproblems recursively. If subproblems are small enough (base case), solve directly.
  • Combine: Merge the solutions of subproblems into the solution for original problem $P$.
  • Real Programming Examples: Binary Search ($O(\log n)$), Merge Sort ($O(n \log n)$), Quick Sort.

2. Brainstorming Technique:

  • A group creativity technique where developers collaborate to generate a large list of spontaneous ideas and architectural strategies to solve a problem without initial criticism.
  • It consists of two phases: Idea Generation Phase (quantity over quality) and Evaluation / Pruning Phase (analyzing feasibility, cost, algorithmic efficiency, and constraints).

3. Trial and Error (Heuristic Search):

  • A fundamental problem-solving method where multiple attempts/hypotheses are tried until a successful result is found or an error is detected.
  • Used in programming for debugging unknown edge cases and in artificial intelligence backtracking algorithms (e.g., solving Sudoku, N-Queens problem).

Q31. Write a complete C program to multiply two $3 \times 3$ matrices. Explain the mathematical condition and analyze time complexity.

Condition for Matrix Multiplication: Multiplication between matrix $A_{m \times k}$ and matrix $B_{k \times n}$ is mathematically valid if and only if the number of columns in the first matrix equals the number of rows in the second matrix. The resulting matrix $C$ has dimensions $m \times n$.

#include <stdio.h>

int main() {
    int a[3][3], b[3][3], c[3][3];
    int i, j, k;

    printf("Enter 9 elements of Matrix A (3x3):\n");
    for (i = 0; i < 3; i++)
        for (j = 0; j < 3; j++)
            scanf("%d", &a[i][j]);

    printf("Enter 9 elements of Matrix B (3x3):\n");
    for (i = 0; i < 3; i++)
        for (j = 0; j < 3; j++)
            scanf("%d", &b[i][j]);

    // Matrix Multiplication logic using 3 nested loops
    for (i = 0; i < 3; i++) {
        for (j = 0; j < 3; j++) {
            c[i][j] = 0;
            for (k = 0; k < 3; k++) {
                c[i][j] += a[i][k] * b[k][j];
            }
        }
    }

    printf("\nResultant Product Matrix C (3x3):\n");
    for (i = 0; i < 3; i++) {
        for (j = 0; j < 3; j++) {
            printf("%d\t", c[i][j]);
        }
        printf("\n");
    }

    return 0;
}
Complexity Analysis:
  • Time Complexity: $O(n^3)$ because there are three nested loops iterating from $0$ to $2$. For arbitrary $n \times n$ matrices, it requires $n^3$ multiplications.
  • Space Complexity: $O(n^2)$ to store the matrices in two-dimensional contiguous memory arrays.

Q34. What are Header Files in C? Explain Standard Library Headers vs User-Defined Header Files, the difference between #include <...> and #include "...", and how Header Guards prevent multiple inclusion errors.

🔥 Repeated: 2016, 2019 15 Marks
✍️ Model Answer:
1. Definition and Role of Header Files:

A header file in C is a source file with the .h extension that contains function prototypes, macro definitions, data structure definitions (struct, union), and global variable declarations intended to be shared across multiple source (.c) files. They enable modular programming, information hiding, and clean separate compilation.

2. Standard Library Headers vs User-Defined Headers:
Category Syntax Search Directory Mechanism Common Examples
Standard Library Headers #include <filename.h> Preprocessor searches exclusively in standard system/compiler include directories (e.g., /usr/include or MinGW include folder). <stdio.h> (I/O: printf, scanf)
<stdlib.h> (malloc, exit, rand)
<string.h> (strlen, strcpy, strcmp)
<math.h> (sqrt, pow, sin, cos)

"student_records.h"
"matrix_ops.h"
3. What Does a Header File Typically Contain?
  • Function Prototypes: Informs the compiler of function names, return types, and parameter lists without providing implementation bodies (e.g., int computeGCD(int a, int b);).
  • Macro & Constant Definitions: Symbolic constants like #define MAX_BUFFER 1024.
  • Type Definitions: Custom typedef and struct templates.
  • External Variable Declarations: Using extern int globalErrorCode;.
4. The Multiple Inclusion Problem and Header Guards:

When multiple .c or .h files include the same header file directly or indirectly, the compiler encounters duplicate structure or variable definitions, causing compilation failures. To prevent this, standard C employs Header Guards using preprocessor conditional directives:

/* File: my_math.h */
#ifndef MY_MATH_H    /* If MY_MATH_H is not yet defined */
#define MY_MATH_H    /* Define MY_MATH_H */

// Function Prototypes
int add(int a, int b);
int multiply(int a, int b);
double power(double base, int exp);

#endif /* MY_MATH_H */

How it works: The first time the file is included, MY_MATH_H is undefined, so the preprocessor defines it and processes the contents. On any subsequent inclusion during the same compilation unit, #ifndef evaluates to false and the entire header body is skipped instantly!

Q35. Explain Local and Global Variables with respect to scope, lifetime, memory allocation, and default initial values. Illustrate Variable Shadowing with a complete C demonstration program.

🔥 Repeated: 2017 15 Marks
✍️ Model Answer:

In C programming, the accessibility and duration of any identifier are governed by two fundamental concepts: Scope (where the variable can be accessed) and Lifetime / Storage Duration (how long the variable occupies memory during execution).

1. Detailed Comparison Table: Local vs Global Variables:
Feature / Metric Local Variable Global Variable
Declaration Location Declared inside a function body or compound block enclosed by { ... }. Declared outside all functions, typically at the top of the C source file.
Scope (Visibility) Block Scope: Accessible only within the enclosing function or block where declared. File Scope: Accessible throughout the entire source file from the point of declaration.
Lifetime Created when function/block execution begins and destroyed immediately when the block exits. Retained in memory throughout the entire duration of the program execution from start to finish.
Memory Segment Allocated dynamically on the Call Stack. Allocated statically in the Data Segment (BSS if uninitialized, initialized data segment if initialized).
Default Initial Value Contains unpredictable Garbage Values if not explicitly initialized by the programmer. Automatically initialized to Zero (0, 0.0, or NULL) by the runtime environment.
Storage Class Default is auto (can also be register or static). Default is external linkage (extern). Can be restricted to current file using static.
2. Variable Shadowing (Name Precedence Rule):

When a local variable within an inner block is declared with the exact same identifier name as a global variable, the local variable shadows (hides) the global variable within that scope. All read and write operations inside the block operate strictly on the local instance.

3. Complete Demonstration C Program:
#include <stdio.h>

int counter = 100;

void testFunction() {
    // Accesses global variable counter
    printf("[testFunction] Global counter value: %d
", counter);
    counter += 25; // Modifying global variable
}

int main() {
    printf("[main: Start] Global counter value: %d
", counter);

    // LOCAL VARIABLE shadowing the global variable of identical name
    int counter = 5; 
    printf("[main: Local Scope] Shadowed local counter: %d
", counter);

    // Inner block demo
    {
        int counter = 999; // Inner block variable shadows main's local counter
        printf("[main: Inner Block] Deeply nested counter: %d
", counter);
    }

    printf("[main: Local Scope] Local counter restored: %d
", counter);

    // Calling external function that operates on global counter
    testFunction();
    printf("[main: End] Global counter after testFunction: %d
", counter); // Still prints local!

    return 0;
}
