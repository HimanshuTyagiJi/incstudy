Practical Lab Examination Guidelines (BCA-306P & BCA-307P)

Semester 3 features two dedicated external lab evaluations carrying 50 marks each:

  • BCA-306P (Data Structures Lab): External examiners evaluate candidates on real-time coding of linked lists, stack-based infix-to-postfix evaluators, binary tree traversals (Inorder, Preorder, Postorder), and sorting algorithms in C/C++.
  • BCA-307P (C++ Lab): Focuses on object-oriented programming implementations: complex number addition via operator overloading, multiple inheritance with virtual base classes, runtime polymorphism using virtual functions, and file stream handling.
  • Viva Voce & Lab Records: Candidates must maintain certified, signed lab record books containing at least 25 standard programs with problem statements, algorithms, source code, and sample terminal output runs.

Frequently Asked Questions (CCSU BCA Semester 3)

How are external theory marks distributed in Semester 3?

All 5 theory subjects carry 75 external university marks and 25 internal assessment marks. The 75-mark paper runs for 3 hours across Section A (15 Marks, 5 short questions), Section B (15 Marks, attempt 2 of 3 questions), and Section C (45 Marks, attempt 3 of 5 long questions).

Which is the most scoring theory subject in Semester 3?

Elements of Statistics (BCA-305) and Object-Oriented Programming with C++ (BCA-301) yield the highest scores because answers can be verified mathematically and algorithmically with standard formula steps and working code outputs.
