CCSU BCA 5th Semester Examination Blueprint

Official Odd Semester Exam Marking Pattern

External University Theory (75 Marks) + Internal Assessment (25 Marks)
Duration: 3 Hours

Section A: Very Short Answer Questions (Mandatory)

5 Qs × 3 Marks = 15 Marks

5 compulsory conceptual questions covering all 5 syllabus units. Answers required in approx 75 words each.

Section B: Short Answer Questions

Attempt 2 out of 3 Qs = 15 Marks

Medium-length analytical questions requiring diagrams, Java code snippets, or normalization steps (7.5 marks each).

Section C: Detailed Long Answer Questions

Attempt 3 out of 5 Qs = 45 Marks

High-weightage descriptive questions with complete code, ER diagrams, routing algorithms, or numerical derivations (15 marks each).

Detailed Unit-Wise Syllabus & Subject Guide

1. BCA-501: Introduction to DBMS (Database Management Systems)

Covers relational database theory, SQL query construction, schema normalization, and transaction processing:

  • Unit I (Database Architecture & Data Models): File systems vs DBMS, three-schema architecture (External, Conceptual, Internal), data independence, Entity-Relationship (ER) modeling (entities, attributes, cardinality, weak entities, generalization/specialization).
  • Unit II (Relational Model & Algebra): Relational model concepts, relational integrity constraints (domain, key, referential integrity), Relational Algebra operations (select, project, union, set difference, Cartesian product, joins: natural, theta, outer join).
  • Unit III (SQL - Structured Query Language): DDL (CREATE, ALTER, DROP), DML (SELECT, INSERT, UPDATE, DELETE), aggregate functions, GROUP BY, HAVING, nested subqueries, views, and integrity constraints.
  • Unit IV (Relational Database Design & Normalization): Functional dependencies (Armstrong's axioms), closure of attribute sets, canonical cover. Normal forms: 1NF, 2NF, 3NF, Boyce-Codd Normal Form (BCNF), lossless join decomposition, and dependency preservation.
  • Unit V (Transaction Processing & Concurrency Control): ACID properties of transactions, serializability (conflict vs view serializability), concurrency control protocols (two-phase locking - 2PL, timestamp ordering), deadlock handling.
  • Recommended Textbook: Database System Concepts by Abraham Silberschatz, Henry F. Korth & S. Sudarshan (McGraw Hill).

2. BCA-502: Java Programming & Web Design

Focuses on platform-independent Object-Oriented software engineering and graphical user interfaces:

  • Unit I (Java Architecture & Fundamentals): Features of Java, Java Virtual Machine (JVM), JDK, JRE, byte-code execution model, primitive data types, type casting, operators, arrays.
  • Unit II (Object-Oriented Concepts in Java): Classes, objects, constructor overloading, this and super keywords, method overriding, abstract classes, interfaces, multiple inheritance via interfaces, packages and access specifiers.
  • Unit III (Exception Handling & Multithreading): Checked vs unchecked exceptions, try, catch, finally, throw, throws, custom exceptions. Java thread life cycle, creating threads (extending Thread class vs implementing Runnable), thread priorities, synchronization, and inter-thread communication (wait(), notify()).
  • Unit IV (Java I/O & Collections Framework): Byte streams vs Character streams, file reading/writing, introduction to Collections (ArrayList, HashMap, Iterator).
  • Unit V (AWT, Swing & Event Delegation Model): AWT vs Swing components, layout managers (FlowLayout, BorderLayout, GridLayout), Event handling (Event Listeners, Event Adapters), building GUI calculator and registration forms.
  • Recommended Textbook: Java: The Complete Reference by Herbert Schildt (McGraw Hill).

3. BCA-503: Computer Network

Explores modern telecommunication architectures, network protocols, routing, and cryptography:

  • Unit I (Network Fundamentals & Topologies): LAN, MAN, WAN, network topologies (Bus, Star, Ring, Mesh, Hybrid), transmission modes (simplex, half-duplex, full-duplex), guided media (twisted pair, coaxial, fiber optic) vs unguided media.
  • Unit II (Reference Models & Data Link Layer): ISO-OSI 7-Layer model vs TCP/IP protocol suite, framing methods, error detection (Parity, Checksum, CRC), flow control protocols (Stop-and-Wait, Sliding Window, Go-Back-N, Selective Repeat).
  • Unit III (Medium Access Control - MAC): Channel allocation, Aloha (Pure vs Slotted), CSMA/CD (Ethernet standard IEEE 802.3), CSMA/CA, token ring.
  • Unit IV (Network Layer & IP Addressing): IPv4 addressing classes, subnetting, CIDR notation, IPv6 overview, Routing algorithms (Distance Vector Routing, Link State Routing), ARP, RARP, ICMP.
  • Unit V (Transport Layer & Network Security): TCP vs UDP, TCP 3-way handshake, port numbers, congestion control. Network security fundamentals: symmetric key cryptography (DES, AES), asymmetric key cryptography (RSA algorithm), firewalls, and digital signatures.
  • Recommended Textbook: Computer Networks by Andrew S. Tanenbaum & David J. Wetherall (Pearson).

4. BCA-504: Numerical Methods

Provides computational algorithms for solving non-linear equations, linear systems, and differential calculus:

  • Unit I (Solutions of Non-Linear Equations): Errors in numerical computation (absolute, relative, percentage errors), Bisection method, Regula-Falsi method, Newton-Raphson method (order of convergence).
  • Unit II (Simultaneous Linear Algebraic Equations): Direct methods: Gauss Elimination method, Gauss-Jordan method. Iterative methods: Jacobi's iteration method, Gauss-Seidel iteration method (convergence criteria).
  • Unit III (Finite Differences & Interpolation): Forward, backward, and central differences. Newton's forward and backward interpolation formulas, Lagrange's interpolation formula for unequally spaced arguments, Divided differences.
  • Unit IV (Numerical Differentiation & Integration): Derivatives using Newton's forward and backward formulas. Numerical integration: Trapezoidal rule, Simpson's 1/3 rule, Simpson's 3/8 rule with error estimates.
  • Unit V (Numerical Solution of Ordinary Differential Equations): Taylor's series method, Euler's method, Modified Euler's method, Runge-Kutta 2nd and 4th order methods (RK-4).
  • Recommended Textbook: Numerical Methods for Scientific and Engineering Computation by M.K. Jain, S.R.K. Iyengar & R.K. Jain (New Age International).

5. BCA-505P: Java Programming & DBMS Practical Laboratory

Hands-on lab exercises and external viva examination (50 Marks):

  • Java Experiments: OOP inheritance hierarchies, multithreaded producer-consumer simulations, custom exception handling, AWT/Swing GUI forms with event listeners, JDBC database connectivity.
  • DBMS Experiments: SQL DDL table creation with primary and foreign key constraints, complex joins, nested subqueries, views, triggers, and PL/SQL cursor procedures.

6. BCA-506P: Minor Project & Industrial Training

Guidelines for 5th-semester project submission and viva defense (50 Marks):

  • Project Scope: Development of a functional web application, desktop utility, or database-driven management system using Java, PHP, Python, or MERN stack.
  • Deliverables: Project synopsis, ER diagrams, normalized database tables, source code repository, and documented test cases.
