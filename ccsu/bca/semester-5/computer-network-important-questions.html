• Total I/O ports required per device: $N - 1$

Q6. What is Framing in Data Link Layer? Explain Bit Stuffing with a concrete example.

🔥 Repeated: 2015, 2018, 2020, 2022 3 Marks
✍️ Comprehensive Solution:

Framing is the process of dividing the physical layer's incoming bitstream into discrete, manageable data units called Frames by inserting recognizable boundary delimiters.

Bit Stuffing (HDLC Standard): Frames begin and end with a reserved flag byte 01111110 (six consecutive 1s). Whenever the transmitting hardware detects five consecutive '1' bits in the user payload data, it automatically injects ("stuffs") an extra '0' bit immediately after them. The receiver hardware strips every '0' appearing immediately after five consecutive '1's, guaranteeing the flag pattern never occurs inside payload data.

Example:
User Data: 011111101111110
Stuffed Stream: 01111101011111010

Q7. Explain the principle of Cyclic Redundancy Check (CRC) for error detection.

🔥 Repeated: 2016, 2018, 2021, 2023 3 Marks
✍️ Comprehensive Solution:

Cyclic Redundancy Check (CRC) is a powerful polynomial division-based error detection code operating on binary bitstrings using Modulo-2 arithmetic (XOR addition without carries):

  1. A predefined generator polynomial $G(x)$ of degree $r$ is agreed upon by both sender and receiver.
  2. Sender appends $r$ zero bits to the original data bitstream $D$ and divides it by $G(x)$ using modulo-2 division.
  3. The remainder of this division (the $r$-bit CRC Checksum) replaces the appended zeros, creating the transmitted frame.
  4. The receiver divides the incoming frame by the identical $G(x)$. If the remainder is strictly zero, the frame is accepted as uncorrupted; otherwise, it is discarded.

Q9. What is CSMA/CD? Why is there a minimum frame size restriction in Ethernet networks?

🔥 Repeated: 2015, 2017, 2020, 2022 3 Marks
✍️ Comprehensive Solution:

CSMA/CD (Carrier Sense Multiple Access with Collision Detection) is the media access control mechanism used in classic shared Ethernet (IEEE 802.3). A station listens to the channel before transmitting ("Listen Before Talk"). If the medium is busy, it waits; if idle, it transmits while continuously listening for collisions ("Listen While Talking"). If a collision occurs, it aborts transmission immediately, broadcasts a 32-bit jam signal, and executes Exponential Backoff.

Minimum Frame Size Rule: For a sender to reliably detect that its own frame collided at the furthest end of the cable, the sender must still be actively transmitting when the reflected collision signal arrives back. Hence, Frame Transmission Time ($T_{ ext{trans}}$) must be at least twice the maximum Propagation Delay ($T_{ ext{prop}}$):

$$ rac{ ext{Frame Size}}{ ext{Bandwidth}} \ge 2 imes T_{ ext{prop}} \implies ext{Min Frame Size} = 2 imes T_{ ext{prop}} imes ext{Bandwidth}$$

In standard 10 Mbps Ethernet, this calculates to exactly 64 bytes (512 bits).

Q11. Explain the role of a Subnet Mask and Default Gateway in IP networking.

🔥 Repeated: 2015, 2017, 2019, 2021 3 Marks
✍️ Comprehensive Solution:
  • Subnet Mask: A 32-bit bitmask of contiguous 1s followed by 0s that a host uses to perform a bitwise logical AND operation with its IP address. This partitions the IP address into two components: the Network ID (bits set to 1) and the Host ID (bits set to 0). It informs the host whether a destination IP is on the local subnet or an outside remote network.
  • Default Gateway: The local IP address of the router interface connected to the host's subnet. When a host determines that a destination IP is outside its local subnet, it encapsulates the packet in a frame addressed to the Default Gateway's MAC address for external routing.

Q14. Describe the three steps of the TCP Three-Way Handshake for connection establishment.

🔥 Repeated: 2016, 2018, 2020, 2022 3 Marks
✍️ Comprehensive Solution:
  1. Step 1 (SYN): Client sends a TCP segment with the SYN flag set to 1 and an initial sequence number $ISN_c = x$ to the server: SYN(Seq=x). Client enters SYN-SENT state.
  2. Step 2 (SYN-ACK): Server acknowledges the client's request with ACK = x + 1, sets its own sequence number $ISN_s = y$, and sets both SYN and ACK flags: SYN-ACK(Seq=y, Ack=x+1). Server enters SYN-RECEIVED state.
  3. Step 3 (ACK): Client responds with an acknowledgment ACK = y + 1 with Seq = x + 1: ACK(Seq=x+1, Ack=y+1). Both client and server enter the ESTABLISHED state, ready for full-duplex data transfer.

Q17. Explain the Sliding Window Flow Control Protocol. Compare Go-Back-N ARQ and Selective Repeat ARQ with sender/receiver window sizes and retransmission strategies.

🔥 Repeated: 2015, 2018, 2020, 2022 7.5 Marks
✍️ Comprehensive Solution:

In Sliding Window Protocols, multiple frames can be in transit simultaneously without waiting for an immediate individual acknowledgment for each frame, keeping the high-bandwidth link fully utilized.

Feature Go-Back-N (GBN) ARQ Selective Repeat (SR) ARQ
Sender Window Size ($W_s$) $W_s = 2^m - 1$ (where $m$ is the sequence number bits). $W_s = 2^{m-1}$ (Half the sequence number space).
Receiver Window Size ($W_r$) Strictly $W_r = 1$ (Accepts only the single expected frame in exact sequence). $W_r = 2^{m-1}$ ($W_s = W_r$). Out-of-order frames within the window are buffered.
Damaged / Lost Frame Reaction Discards all subsequent frames even if received correctly. Sender must retransmit the damaged frame plus all $N$ frames sent after it! Receiver buffers out-of-order frames and sends Negative Acknowledgment (NACK). Sender retransmits ONLY the specific damaged frame.
Acknowledgment Type Cumulative ACKs ($ACK(n)$ confirms all frames up to $n-1$). Individual / Selective ACKs.
Buffer Complexity Minimal. Receiver requires only 1 frame buffer. High. Receiver requires sorting and buffering logic.

Q20. Discuss the Distance Vector Routing Algorithm. What is the Count-to-Infinity Problem? Explain how Split Horizon and Poison Reverse resolve it.

🔥 Repeated: 2015, 2017, 2020, 2022 7.5 Marks
✍️ Comprehensive Solution:

Distance Vector Routing (RIP Protocol): An iterative, asynchronous routing algorithm based on the Bellman-Ford equation. Each router maintains a routing table containing the estimated shortest distance to every destination network and the next-hop router. Periodically, every router broadcasts its entire routing table only to its immediate direct neighbors.

$$D_x(y) = \min_v \{ c(x, v) + D_v(y) \}$$
The Count-to-Infinity Problem:

While good news (link cost reductions) travels fast, bad news (link failures) propagates very slowly. Consider a linear topology $A - B - C$. If the link between $B$ and $C$ fails, $B$ detects the failure. However, $A$ had previously advertised that it can reach $C$ with cost 2 (via $B$). $B$ mistakenly thinks $A$ has an alternative path to $C$, so $B$ updates its cost to $C$ as $2 + 1 = 3$ via $A$. In the next round, $A$ updates its cost to $3 + 1 = 4$ via $B$. The metric increments indefinitely ($16 = \infty$ in RIP) in a slow routing loop.

Mitigation Techniques:
  • Split Horizon: A router does not advertise routes back over the same interface from which it learned them. (If $A$ learns the route to $C$ through $B$, $A$ will never advertise a route to $C$ back to $B$).
  • Poison Reverse: $A$ advertises the route back to $B$, but explicitly sets the metric to $\infty$ (16): "I can reach $C$ via you, so to me, reaching $C$ through anyone else is impossible." This immediately terminates the circular dependency.

Q21. Explain Link State Routing (OSPF). Describe Dijkstra's Shortest Path Algorithm steps with a network graph.

🔥 Repeated: 2016, 2018, 2021, 2023 7.5 Marks
✍️ Comprehensive Solution:

In Link State Routing (e.g. OSPF), every router discovers its direct neighbors, learns their link costs, constructs a Link State Packet (LSP), and floods it reliably to all routers in the entire autonomous system. Every router builds an identical global topology map of the network and independently runs Dijkstra's Shortest Path Algorithm with itself as the root to build its routing table.

Dijkstra's Algorithm Steps:
  1. Initialize set $N' = \{u\}$ (source node). For all other nodes $v$, set $D(v) = c(u, v)$ if directly connected, else $\infty$.
  2. Find node $w otin N'$ such that $D(w)$ is a minimum. Add $w$ to $N'$.
  3. Update $D(v)$ for all neighbors $v otin N'$ of $w$: $$D(v) = \min(D(v), D(w) + c(w, v))$$
  4. Repeat steps 2 and 3 until all nodes are included in $N'$.
Advantage over Distance Vector: OSPF converges rapidly ($O(V^2)$ or $O(E \log V)$), produces zero routing loops, and generates minimal network overhead once converged.

Q22. Explain Congestion Control in TCP. Detail the four operational phases: Slow Start, Congestion Avoidance, Fast Retransmit, and Fast Recovery.

🔥 Repeated: 2015, 2017, 2019, 2022 7.5 Marks
✍️ Comprehensive Solution:

TCP modulates its transmission rate using a dynamic variable called the Congestion Window (cwnd). The actual window sent is $\min( ext{cwnd}, ext{rwnd})$.

  1. Slow Start Phase: Starts with $ ext{cwnd} = 1 ext{ MSS}$. For each ACK received, $ ext{cwnd}$ doubles every Round Trip Time (RTT) (exponential growth: $1 o 2 o 4 o 8 \dots$) until reaching the Slow Start Threshold (ssthresh).
  2. Congestion Avoidance (AIMD): When $ ext{cwnd} \ge ext{ssthresh}$, growth switches to linear: $ ext{cwnd}$ increases by exactly $1 ext{ MSS}$ per RTT (Additive Increase) to gently probe for available link bandwidth.
  3. Fast Retransmit: If the sender receives 3 duplicate ACKs for a missing packet, it infers packet loss immediately without waiting for the retransmission timer to expire, and retransmits the missing segment at once.
  4. Fast Recovery (TCP Reno): After 3 duplicate ACKs, $ ext{ssthresh}$ is halved ($ ext{ssthresh} = ext{cwnd} / 2$) and $ ext{cwnd}$ is set to $ ext{ssthresh} + 3 ext{ MSS}$ (Multiplicative Decrease). It stays in Congestion Avoidance rather than collapsing back to 1 MSS.

Q23. Explain the RSA Public-Key Cryptosystem. Given prime numbers $p = 3$ and $q = 11$, and encryption exponent $e = 7$. Compute the private decryption key $d$. Encrypt plaintext message $M = 5$ and verify decryption.

🔥 Repeated: 2014, 2016, 2018, 2021, 2023 7.5 Marks
✍️ Comprehensive Solution:
Step 1: Compute Modulus $n$ and Euler's Totient $\phi(n)$:
  • $n = p imes q = 3 imes 11 = \mathbf{33}$
  • $\phi(n) = (p - 1)(q - 1) = (3 - 1)(11 - 1) = 2 imes 10 = \mathbf{20}$
Step 2: Verify Encryption Key $e$ and Compute Decryption Key $d$:
  • Given $e = 7$. Check $\gcd(e, \phi(n)) = \gcd(7, 20) = 1$ (Valid).
  • Calculate private key $d$ such that $(d imes e) \equiv 1 \pmod{\phi(n)}$: $$(d imes 7) \equiv 1 \pmod{20} \implies 7d = 20k + 1$$ For $k = 1$: $7d = 21 \implies d = \mathbf{3}$.
  • Public Key: $\{e, n\} = \{7, 33\}$ • Private Key: $\{d, n\} = \{3, 33\}$.
Step 3: Encryption of Plaintext $M = 5$:
$$C = M^e \pmod n = 5^7 \pmod{33}$$
  • $5^2 = 25 \equiv -8 \pmod{33}$
  • $5^4 = (-8)^2 = 64 \equiv 31 \equiv -2 \pmod{33}$
  • $5^6 = 5^4 imes 5^2 \equiv (-2) imes (-8) = 16 \pmod{33}$
  • $C = 5^7 = 5^6 imes 5 \equiv 16 imes 5 = 80 \pmod{33}$
  • $80 = (2 imes 33) + 14 \implies \mathbf{C = 14}$ (Ciphertext).
Step 4: Decryption of Ciphertext $C = 14$:
$$M = C^d \pmod n = 14^3 \pmod{33}$$
  • $14^2 = 196 = (5 imes 33) + 31 \equiv 31 \equiv -2 \pmod{33}$
  • $14^3 = 14^2 imes 14 \equiv (-2) imes 14 = -28 \equiv \mathbf{5} \pmod{33}$
  • Original Message Restored: $M = 5$. Proof verified!

Q25. Detail the Sliding Window Flow Control Protocols (Stop-and-Wait, Go-Back-N, and Selective Repeat). Derive the mathematical channel utilization formula $\eta = rac{N}{1 + 2a}$. Solve a numerical problem calculating optimal sender window size for a high-bandwidth satellite link.

🔥 Repeated: 2015, 2017, 2019, 2021, 2023 15 Marks
✍️ Comprehensive Solution:
1. Derivation of Channel Utilization ($\eta$):

Q30. Discuss Network Security Principles (Confidentiality, Integrity, Authentication, and Non-repudiation). Explain how Digital Signatures guarantee Authenticity and Non-Repudiation with an architectural diagram. Contrast Packet-Filtering, Application-Gateway, and Stateful-Inspection Firewalls.

✍️ Comprehensive Solution:
1. The Four Pillars of Network Security:
  • Confidentiality: Only authorized sender and receiver should understand the contents of the transmitted message (achieved via Encryption).
  • Message Integrity: Ensures the message has not been altered, injected, or tampered with in transit (achieved via Cryptographic Hash Functions like SHA-256).
  • Authentication: Sender and receiver can verify each other's legal identity (achieved via Digital Certificates and PKI).
  • Non-Repudiation: The sender cannot falsely deny having sent the message once transmitted (achieved via Digital Signatures).
