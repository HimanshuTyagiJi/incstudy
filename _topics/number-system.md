<h2 id="introduction">Introduction</h2><p>A number system represents numbers using symbols and rules. In computing, binary, decimal, octal and hexadecimal systems are commonly discussed.</p><h2 id="number-types">Types of number systems</h2><ul><li><strong>Decimal:</strong> base 10, using digits 0–9.</li><li><strong>Binary:</strong> base 2, using digits 0 and 1.</li><li><strong>Octal:</strong> base 8, using digits 0–7.</li><li><strong>Hexadecimal:</strong> base 16, using digits 0–9 and A–F.</li></ul><h2 id="conversions">Number conversions</h2><p>To convert a positive decimal integer to binary, repeatedly divide the number by 2 and read the remainders from bottom to top. Check the method and scope against your course material.</p><div class="notice-box">This is starter learning content, not a verified university syllabus or complete exam notes.</div>
